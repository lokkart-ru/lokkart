# Lokkart — поставка мебельного щита из массива

Lokkart (Локкарт) — поставщик мебельного и столярного щита из массива твёрдых пород в Москве. Работаем с 2010 года, офис и выдача — 51-й км МКАД.

Породы: дуб, ясень, лиственница, бук, сосна, берёза. Два типа склейки: цельноламельный — из цельных ламелей по всей длине, без поперечных стыков, для видовых поверхностей; сращенный — ламели срощены на микрошип, он спокойнее ведёт себя при перепадах влажности и дешевле. Сорта А, В и Кантри. Основные толщины 18, 20 и 40 мм. Влажность 8±2% — щит приходит готовым к работе в отапливаемом помещении.

Кроме щита поставляем комплектующие для лестниц — ступени, подступенки, площадки, поручни, тетиву, — шпонированные плиты, натуральный шпон, масло-воск. Лестницы, подоконники, столешницы и столы — на заказ.

Подбираем щит под задачу: считаем раскрой по чертежу или размерам проёма, подсказываем, где достаточно сращенного, а где нужна цельная ламель, пилим в размер перед отгрузкой. Ответ по спецификации — наличие, срок, цена — в течение рабочего дня.

Каждую партию принимаем по геометрии и влажности: толщина, плоскостность, косина реза, расслоения, выпавшие сучки, соответствие заявленному сорту. Щит с отклонением не отгружаем и меняем по обоснованной претензии.

Отгрузка ежедневно по Москве и области, в регионы — транспортными компаниями. Работаем по договору.
